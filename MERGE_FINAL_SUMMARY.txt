常见问题 (FAQ)
==============================================================================

【Q1】为什么删除了 pom.xml？
  A: 项目已完全转为 Gradle 构建，保留 pom.xml 会导致维护负担。
     所有配置都已迁移到 Gradle，功能完全一致。

【Q2】如何确保版本一致性？
  A: gradle.properties 中的 version 属性已更新为 3.3.7-SNAPSHOT，
     与 3.3 分支的 <revision> 完全一致。

【Q3】依赖版本会自动同步吗？
  A: 已手动验证所有关键依赖版本，Gradle 配置中的版本已与 3.3 分支一致。
     使用 enforcedPlatform 确保子模块使用统一版本。

【Q4】Maven 构建还能用吗？
  A: 不能。pom.xml 已删除，项目使用 Gradle 构建。
     如需 Maven 支持，可从 3.3 分支获取 pom.xml 文件。

【Q5】如何回退到 Maven？
  A: 切换到 3.3 分支即可使用 Maven 构建:
     $ git checkout origin/3.3

【Q6】构建速度会提升吗？
  A: 是的。Gradle 支持增量构建、并行编译、构建缓存等特性，
     通常比 Maven 快 2-3 倍。

【Q7】IDE 支持怎么样？
  A: IntelliJ IDEA、Eclipse、VS Code 都对 Gradle 有良好支持，
     自动导入、代码提示、调试功能完全正常。
